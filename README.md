# agregation

Study notes for the phonology part of the agrégation d'anglais, published at
https://lcontrerasroa.github.io/agregation/

## Structure

- `graphophonemics.html`, `stress.html`, `phonetic-processes.html`, `suprasegmentals.html`, `ssbe-ga.html`: the five chapters (pandoc exports from the Word handout).
- `fleabag.html`, `zadie.html`, `earnest.html`, `angels.html`: practice texts.
- `consonants-vowels.html`: phonemic chart.
- `index.html`: home page, generated by the layout tool.
- `styles.css`, `site.js`: shared stylesheet and progressive enhancements (mobile menu, ruby display modes, "on this page" highlight, collapsible video).
- `tools/apply_layout.py`: wraps every page in the shared layout.

## Updating a chapter

1. Regenerate or edit the page. Only the content matters; the wrapper is rebuilt.
2. Run `python3 tools/apply_layout.py`.
3. Commit.

The tool keeps the original content between `<!-- content:start -->` and `<!-- content:end -->`, so it can be run any number of times. It never changes heading `id`s: external links to anchors (course page, Moodle) keep working.

Transcriptions in the chapters use `<ruby>` elements. The top bar lets readers show them above the words, inline in parentheses, or blurred (quiz mode, tap to reveal).
